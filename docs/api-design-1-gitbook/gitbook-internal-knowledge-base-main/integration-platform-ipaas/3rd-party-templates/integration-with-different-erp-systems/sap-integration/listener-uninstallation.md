# Listener Uninstallation

1. In case you will need to reinstall the listener open the file **uninstall.bat** ---->  **Edit**    -----> add **the correct path to your listener.**

![](<../../../../.gitbook/assets/Capture (19).PNG>)

After making sure you have the correct way to the listener inside the file **uninstall.bat**\
**------>** **run it as administrator**

**2.** After that, online\_listener (pepperi\_onlinelistener) will disappear in the “Service” tab in the task manager

![](<../../../../.gitbook/assets/Capture (34).PNG>)
