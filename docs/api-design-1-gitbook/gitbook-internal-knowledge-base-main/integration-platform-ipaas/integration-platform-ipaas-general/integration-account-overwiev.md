# Integration Account Overwiev

You can see different tabs when you go to **integration plugin** **settings** of selected account at

[https://integration.pepperi.com/mgr](https://integration.pepperi.com/mgr)

·        **General Settings** - General plugin settings. You can specify any [setting](https://kbint.pepperi.com/integration-platform-general/tasks-settings) here that could be used in any  of the tasks. Settings in the tasks allow have higher priority than general.

·        [**Dataflow Tasks**](https://kbint.pepperi.com/integration-platform-general/dataflows) – tasks which can import or export data between two apps (for example two different Pepperi accounts, SAP-Pepperi, etc), this tab shows you list of all your dataflow task and give access to configuration of each of this tasks.

·        [**Webhook Tasks**](https://kbint.pepperi.com/integration-platform-general/webhooks) – tasks which will be completed automatically after some actions in your app (for example Invoice will be created automatically after somebody make new order), this tab shows you list of all your webhook task and give access to configuration each of this tasks.

·        [**UI Tasks**](https://kbint.pepperi.com/integration-platform-general/ui-tasks) – tasks which allow you to create your own HTML\CSS\JS interface and logic, this tab shows you list of all your UI task and give access to configuration each of this tasks.

·        **Manage Tasks** – this tab allows you to manage each type of tasks above. You can create new task with type you need, import task from another account, copy task to another account or copy to the same account and make some changes. For each new task you can set Name, Application, Source Object and Target Object

·        **Scheduled Jobs** – allows you to configure schedule of your dataflow tasks in order to this tasks work automatically in schedule you set. All your dataflow tasks will be automatically added to scheduled jobs but they will be turn off. If you want to turn it on you can set “enabled” in your current scheduled job and set schedule you need. Also you can add other dataflow task to you job and set an order they will be done.

·        Logs (**Dataflow logs**, **UI logs**, **Transaction logs**) – in this tabs you can find logs of your tasks

·        **Information tab** – this tab show you name and id number of your account in Integration
