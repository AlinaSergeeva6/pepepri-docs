# Custom Flows Templates

### Prerequisites

Install the required addons, specified in [pages-with-flows.md](../pages-with-flows.md "mention")

### **Example**

The following **templates** (except for **Open Online - Demos Transaction**) are implemented on **IG Design Group** (6766) (30012981) environment, admin: **admin@igdesigngroup.com.au**.

### Flows Templates

1. **Get Accounts for Filter**\
   This template is used to allow Multi-Account-Buyers to select account from dropdown. \
   Read the article [get-accounts-for-filter.md](get-accounts-for-filter.md "mention")
2. **Create and Navigate to Transaction or Item Details**\
   This template allows user to open transaction.\
   Read the article [create-and-navigate-to-transaction-or-item-details.md](create-and-navigate-to-transaction-or-item-details.md "mention")\
   <mark style="background-color:purple;">Alternatively</mark>, **Open Online - Demos Transaction** template can be configured, see article [open-online-demos-transaction.md](open-online-demos-transaction.md "mention")
3. **Navigate By Link**\
   This template allows user to navigate to app.pepperi.com resources. \
   Read the article [navigate-by-link.md](navigate-by-link.md "mention")
4. **Open External Link**\
   This template allows user to navigate to external link. \
   Read the article [open-external-link.md](open-external-link.md "mention")
5. **Adding Dynamic Data to the Page**\
   This template allows to display dynamic data from transaction fields.\
   Read the article [adding-dynamic-data-to-the-page.md](../../add-ons-manuals/pages-add-on/adding-dynamic-data-to-the-page.md "mention")
