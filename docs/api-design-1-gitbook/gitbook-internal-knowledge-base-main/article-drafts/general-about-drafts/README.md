# General about Drafts

{% hint style="info" %}
This section will be used for adding drafts of new articles directly to Gitbook, without the need of modifying everything somewhere on the side(Word etc.). Drafts can be filled out during the meeting regarding article's topic or right after it. Initially draft contains basic sc for all the features that should be explained&#x20;
{% endhint %}

### How to work with drafts&#x20;

1. Duplicate the default draft inside gitbook
2. Fill out all the neccessary information, recieved for the interviewee
3. report to your team lead or TPM team lead

### General Rules For Drafts

1. Drafts must be well structured and follow the plan.
2. Set of sections in the draft sample is mandatory
3. **Effort Estimations** must be asked from the interviewee. He or she should give the actual time, spent on implementing the functionality.
4. **Advantages and Disadvantages** section requires your own opinion as well as opinion of interviewee, it will be checked by the reviewer afterwasds.
5. All the sections must include detailed explanation of all the functionality, so it could be easily implemented by other workers.
