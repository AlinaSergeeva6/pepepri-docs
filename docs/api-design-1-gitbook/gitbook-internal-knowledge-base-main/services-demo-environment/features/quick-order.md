# Quick Order

<figure><img src="../../.gitbook/assets/image (88).png" alt=""><figcaption></figcaption></figure>

This functionality gives you an opportunity to add items to the transaction using a search line or barcode scanner. You can also use an interface keyboard provided in this custom form. The switch scanner mode provides you with an option to either duplicate the item if added for the second time or discard it. After adding an item, you can edit the quantity or delete it.

<figure><img src="../../.gitbook/assets/image (269).png" alt=""><figcaption></figcaption></figure>

**How to use:**

You can access it via the menu in the order center. Press “QuickOrder”, proceed with adding and editing the items, and press “Done”.

**How to copy:**

Copy the QuickOrder custom form.
