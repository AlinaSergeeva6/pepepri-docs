# Shelf Labels PDF

<div><figure><img src="../../.gitbook/assets/image10-49.png" alt=""><figcaption></figcaption></figure> <figure><img src="../../.gitbook/assets/image11-51.png" alt=""><figcaption></figcaption></figure></div>

The feature allows you to create a pdf that will have needed items information on predefined cells and will be printed on a specialized sticky paper with defined empty cells.

It can be accessed through the program button in the menu or by adding it to your workflow.

**How to copy:**

To use it, copy the Trigger Send PDF Shelf Labels webhook and all dataflow tasks from Shelf Labels Scheduled Job.

![](<../../.gitbook/assets/CleanShot 2022-11-18 at 10.13.24@2x (1).png>)![](<../../.gitbook/assets/CleanShot 2022-11-18 at 10.16.21@2x (4).png>)

In the case of using this feature from the mobile app, you need to add an additional dataflow task to your item export job that will take after items upload all the item images links to keep this data.
