# Alerts

Each alert in the list has its own page\
The format:\
**Name:** {Alert Name}

* The alert name is unique and serves as the identifier for the alert.

\
**Description:** {Alert Short Description}

* A brief summary of the alert.
* This description may change over time.

**Broadcast Channel:** `{System|External}`

* **System**: The alert is managed and triggered by Pepperi.
* **External**: The alert is managed and triggered by an external alerting mechanism

#### Additional Sections - not part of the Alert itself

Each alert page also includes the following sections:

**Description**

* A detailed explanation of the alert, including its origin, cause, and relevant background information.

**Action**

* Clear, actionable recommendations describing what steps should be taken manually in response to the alert.
