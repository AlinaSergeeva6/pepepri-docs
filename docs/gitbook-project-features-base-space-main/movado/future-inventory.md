# Future inventory

This custom form shows information about future receiving for specified items only. SKU(s) are chosen inside the order using dedicated checkbox “View Future Inventory”:

<figure><img src="../.gitbook/assets/image (18).png" alt=""><figcaption></figcaption></figure>

Then information about selected items is available inside the custom form itself:<br>

<figure><img src="../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure>

Using checkbox instead of item scope prevents overloading and performance issues of the custom form. This solution also let view information on devices without connection.
