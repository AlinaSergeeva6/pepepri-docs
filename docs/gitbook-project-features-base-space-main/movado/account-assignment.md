# Account assignment

{% hint style="info" %}
Sales Reps and Admins can use the mentioned UI task to choose and assign accounts to their Sales Organization.&#x20;
{% endhint %}

Core features:

1\. Assign all / filtered customers.

2\. Mark accounts as favorite.

3\. Search for specific record.

4\. Smart Search to filter by specified fields.
