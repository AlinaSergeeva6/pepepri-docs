# Catalog Assignment

{% hint style="info" %}
Movado has some accounts that can have only/additional manual catalogs. For that we use dedicated UI task.
{% endhint %}

### Assignment algorithm:

1. Admin chooses customer from the dropdown.
2. Under “Available Catalogs” remove or leaves already assigned ones.
3. In “Add a catalog” choose the new catalogs that need to assign.
4. On “Confirm changes” click updated record is set on account field.
