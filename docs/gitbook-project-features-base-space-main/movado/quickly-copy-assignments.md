# Quickly Copy Assignments

{% hint style="info" %}
This UI task allows admins to copy Account-Users assignments from one user to another. Also, there is a field for expiration date. Schedule job regularly checks it and remove assignments.
{% endhint %}

The use case can be when one rep goes on vacation and someone else takes on former’s responsibilities for the time being.

After copying, accounts also available for management in the Account Assignment UI.
