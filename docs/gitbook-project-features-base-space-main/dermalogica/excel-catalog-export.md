# Excel Catalog Export

This UI task takes current item scope data and forms XLSX file with applied formatting, filters, Excel formulas and SUM for line totals. This allows the user to check and work with catalog items directly in the spreadsheet, which sometimes can be useful for the reps

<figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>

At the same time, reps on Pepperi mobile app, receive it as a CSV file via email. It also contains formulas and once opened in Excel, those are calculated correctly:
