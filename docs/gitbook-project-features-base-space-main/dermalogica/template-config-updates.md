# Template Config Updates

Dermalogica has specific rules about minimum/preset/step/etc. QTY for some packages. Those rules are defined in UDT and then retrieved inside the transaction.

Editing UDT is not very convenient for some users, so there is a simple and straightforward UI task for that:

<figure><img src="../.gitbook/assets/Screenshot 2026-01-06 at 19.04.12.png" alt=""><figcaption></figcaption></figure>

Button "Download Config" generates and downloads a CSV file that contains information from UDT and also some item info line name and category to help Dermalogica team better identify which products should be updated:

<figure><img src="../.gitbook/assets/Screenshot 2026-01-06 at 19.07.22 (1).png" alt=""><figcaption></figcaption></figure>

After needed changes are done, they click "Update Config", upload file back. UDT is succesfully updated:

<figure><img src="../.gitbook/assets/Screenshot 2026-01-06 at 19.08.28 (1).png" alt=""><figcaption></figcaption></figure>
