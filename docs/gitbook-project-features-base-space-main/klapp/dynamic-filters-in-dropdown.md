# Dynamic filters in dropdown

Dropdown in the custom header made using Homepage Editor. It dynamically takes all possible pairs of Main and Subcategories to replicate the tree of Catalog Filter inside the transaction.

Each category in the dropdown has its own **DeepLink** that on click opens the transaction and applies the corresponding **Smart Filter**. If the user inside the order clicks again on some other option - Smart Filter will be reapplied

{% hint style="info" %}
PRODUCTS has a DeepLink that on click opens the transaction without filters - for new order all products shown but **for existing one previously applied Smart Filters are not cleared**.
{% endhint %}
