# Split Order - Ship Together

{% hint style="info" %}
The "Ship Together" feature allows a customer to receive an order later when all the items are back in stock instead of splitting the order based on item ETA dates.&#x20;
{% endhint %}

### How to use:&#x20;

1. Start a new transaction.
2.  Select in-stock and out-of-stock items:<br>

    <figure><img src="../.gitbook/assets/image (35).png" alt=""><figcaption></figcaption></figure>

    ◾ Such an order will be split:<br>

    <figure><img src="../.gitbook/assets/image (41).png" alt=""><figcaption></figcaption></figure>

◾ Click on "Ship Together" and splitting will be canceled:

<figure><img src="../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure>

3. Click on "Continue": the order will be submitted as one.&#x20;
