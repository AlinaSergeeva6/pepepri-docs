# Overview of the Subscription plans, additional features and estimations for the additional features

{% hint style="info" %}
Pepperi works with 3 types of sellable instances:&#x20;

* Subsrciption plans.
* Additional features which can be included in one of the plans or purchased separately.
* Customization serivces provided by ukrainian team.
{% endhint %}

To simplify the reading, this article will cover each instance one by one as they might be overlapping with one another.

## Subscription plans

Pepperi offers its customers 3 subscriptions plans:\
**Pro**, **Corporate** and **Ultimate.**

Each of the plans contains licenses which give you  access to different features, such as: related items, trade promotions, multi account buyers etc.

### Pro plan:

Pro plan is a basic plan in Pepperi, it contains only the general features, such as transactions, accounts, pricelists and that is it. It does not contain any of the additional features, such as Pages, custom domain, payment gateway or even generic image uploader, therefore, these features will not be mentioned here at all.

{% hint style="info" %}
the list of the containable features is really long, therefore only the non-including features will be mentioned here.
{% endhint %}

**These features are not included into the basic plan:**

***

* IPaaS
* Additional environment(Sandbox, stage etc.)
* Custom Domain
* Homepage editor(earlier Homepage addon, now Pages)
* multiple languages

***

* User profiles
* Users hierarchy
* User profiles
* Buyer profiles
* Multi account buyers
* New Account Creations workflow

***

* multi currency support
* multiple catalogs
* more then 1 prod. transaction
* Promotions
* Multiple activities
* Related items
* Push notifications
* Customer services (Service request (returns etc.), service request history, contact us)

{% hint style="info" %}
Additionally, this plan does not include any of the quick setup features except the default Insights configuration.(read more here)&#x20;
{% endhint %}

## Features overview

{% hint style="info" %}
Since we already got acquainted with this section, lets review the additional features that we provide to our customer on subscription basis, meaning that customer have to purchase additional license despite of their current subscription plan to be able to use the features.
{% endhint %}

### General:

Each feature described in this article is  either a part of a subscription plan or is an additional subscription which means that:

1. Basic configuration for the feature is not billable.
2. Additional configuration, custom logic or any type of additional PS work should be estimated and paid by the customer before the actual work starts.

### Insights:

{% hint style="info" %}
The feature contains **basic** and **advanced** versions. The first version is provided for each customer be default. Advanced version need additional subscription from the customer.
{% endhint %}

{% hint style="warning" %}
Either of the versions does not include configuration services, which have to be done by any of Pepperi team member, therefore any type of work that you do should be estimated and addressed to the customer first.
{% endhint %}

Please, get acquainted with the list of features available for each version:

### Account Balance Manager and Content Management

these 2 feature require additional license to be purchased from any customer.

Since they are both in quick setup, every work related to the quick setup configuration is not billable.\
Any additional service with modifying the feature process, like: custom filter, ui task modification, should be billable.

### Publitas and Avalara Tax calculator

These two features are a part of a quick setup, which actually does not exist yet, so before doing the work, it requires additional consultation with the project manager or sales manager associated with the project.

### Payment Gateway

Such payment gateways like:&#x20;

* Stripe
* Shift4
* Authorize.net
* Credit Guard

Require license to be purchased. Additionally, the basic configuration is not billable. Any additional adjustments should be charged for.

### Advanced Image Uploader

Requires license to be purchased. Additionally, the basic configuration is not billable. Any additional adjustments should be charged for.
