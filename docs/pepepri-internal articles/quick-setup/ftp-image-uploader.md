# FTP Image Uploader

The feature creates dataflow tasks easily and with selected parameters. To use this functionality go to the tools -> quick setup in the Services Demo integration, press **install** in the FTP Image Uploaded block, then press launch, and the new page will be opened.

![](/static/image-934.png)
