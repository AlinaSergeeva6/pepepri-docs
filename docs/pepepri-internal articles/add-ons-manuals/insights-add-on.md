# Insights Add-on

*This guide introduces Pepperi Insights, a feature that enhances decision-making by providing role- and hierarchy-based operational analytics dashboards integrated into the sales process.*

### Overview

Pepperi Insights empowers users to drive smarter buying decisions through operational analytics dashboards tailored to their roles (e.g., Rep, Sales Manager, Buyer) and organizational hierarchy. These dashboards are seamlessly embedded within the Pepperi mobile and Web apps, offering real-time insights to optimize sales performance.

---

### Benefits of Pepperi Insights

Use Insights to focus reps and buyers on key areas, including:

-   **Sales Programs:** Yearly, quarterly, or customer-specific initiatives.
-   **New Product Launches:** Highlighting growth items and periodic promotions.
-   **Targets and KPIs:** Tracking performance against predefined goals.
-   **Sales Statistics:** Detailed metrics for informed decision-making.
-   **Commission Information:** Providing visibility into expected earnings.
-   **Operational Metrics:** Including number of visits, percentage of visits with orders, and coverage versus targets.
-   **Competitive Benchmarking:** How reps perform compared to colleagues (e.g., sales targets per brand or customer).

Insights delivers this information directly within the Pepperi mobile app and Web app, enabling users to access critical data on the go.

### Configuration Process

Insights configuration is performed in the Pepperi back office, allowing administrators to create and publish dashboards using internal Pepperi data and imported external data (e.g., targets, KPIs). The process involves the following modules:

#### Insights Modules

1.  **Data Index:**
    -   Index the fields you want to use for dashboard charts and graphs, ensuring relevant data is available for analysis.

2.  **Data Queries:**
    -   Create queries to summarize indexed fields according to dashboard requirements. Use the graphical UI to select fields and apply filters.

3.  **Pages Layout Designer:**
    -   Utilize a drag-and-drop interface to design dashboard pages tailored to each user profile (e.g., Rep, Sales Manager, Buyer).
