# Transactions status Regular and Draft

*Tasks examples you can find in 'Integration Examples' (6685) , 'SAP -Import Buyer Order(draft)' and 'SAP -Import Buyer Order Lines'*

At integration platform you have opportunity to set transaction type. It could be regular or draft. Regular type is a common transaction and it is a default transaction type, so you have no need to set it manually. Draft type is used when you need working transaction but there will be no purchase.
