# General Description

Custom homepage is the most powerful customization instrument in Pepperi. It allow customers to configure the general view and functionality of Pepperi homepage according to their business needs or make Pepperi environment look like fully functional landing page.

### Structure

Custom homepage itself consist of two configuration files.

**Header.** Header file contains view for the header section of homepage.

**Important: Header customization available for each user profile type such as buyer, admin, rep, manager, etc.**

![](https://alinasergeeva6.github.io/pepepri-docs/static/1-9.png)

Fig 1. Custom Header.

**Body.** Body file contains view and functionality setup for body section of homepage.

**Important: Body customization available only for BUYER profile.**

![](https://alinasergeeva6.github.io/pepepri-docs/static/2-4.png)

Fig 2. Body section.

### Setup

To set the custom homepage header and body first you need to create two config files with **WebApp Customization** type. One for header and another one for Body.

![](https://alinasergeeva6.github.io/pepepri-docs/static/3-4.png)

Fig. 3 File Type.

Place these files in **Company Profile -> WebApp Main Bar -> Profile (Buyer or other)** and you are ready to configure and test your client’s custom homepage.
