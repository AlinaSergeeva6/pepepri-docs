# Dynamic XSLT template - Sorting

It is possible to implement sorting in the order table (string value).

To do this, find this part of code and uncomment it (put the field that you need)

```
 <!--<xsl:sort select="./Column[@ApiName='ItemExternalID']"/>-->
```
