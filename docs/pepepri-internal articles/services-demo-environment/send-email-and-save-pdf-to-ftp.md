# Send Email And Save PDF to FTP

This functionality provides you with the ability to send an email with the content of your choice and then save the copy to the FTP. This can be added as a program to your transaction or you can add it to the workflow for instance as a post action to submit. In this case, after the order is submitted, this feature sends the pdf by mail and then saves a copy of this pdf to FTP. In the case of the program, the same will be done when you press the relevant program button.

![](/static/image-957.png)

**How to copy:**

You can copy the webhook “PDF Email and FTP” on services demo integration or add it as a program, the program is called SendEmailAndSavePDFToFTP.
