# Custom Flows Templates

*This section describes custom Flows and their connected Scripts Templates.*

### Prerequisites

Install the required addons, specified in [Pages with flows](/pepperi/custom-homepages/pages-with-flows.md)

### Example

The following **templates** (except for **Open Online - Demos Transaction**) are implemented on **IG Design Group** (6766) (30012981) environment, admin: **admin@igdesigngroup.com.au**.

### Flows Templates

1.  **Get Accounts for Filter** This template is used to allow Multi-Account-Buyers to select account from dropdown. Read the article [Get Accounts for Filter](/pepperi/custom-homepages/get-accounts-for-filter.md)
2.  **Create and Navigate to Transaction or Item Details** This template allows user to open transaction. Read the article [Create and Navigate to Transaction or Item Details](/pepperi/custom-homepages/create-and-navigate-to-transaction-or-item-details.md) Alternatively, **Open Online - Demos Transaction** template can be configured, see article [Open Online - Demos Transaction](/pepperi/custom-homepages/open-online-demos-transaction.md)
3.  **Navigate By Link** This template allows user to navigate to app.pepperi.com resources. Read the article [Navigate By Link](/pepperi/custom-homepages/navigate-by-link.md)
4.  **Open External Link** This template allows user to navigate to external link. Read the article [Open External Link](/pepperi/custom-homepages/open-external-link.md)
5.  **Adding Dynamic Data to the Page** This template allows to display dynamic data from transaction fields. Read the article [Adding Dynamic Data to the Page](/add-ons-manuals/pricing-module-ppm-add-on/adding-dynamic-data-to-the-page.md)
