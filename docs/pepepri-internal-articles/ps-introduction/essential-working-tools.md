# Essential Working Tools

Before starting work, familiarize yourself with the following tools, which are critical for efficient task execution:

-   **Smartsheet** A project management and team collaboration tool. It helps teams:
    -   Track dates and dependencies associated with projects.
    -   Manage assignments and resources.
    -   Track time. Smartsheet enables users to manage and track projects, deadlines, and workflows effectively.

-   **OpenAir** A project management tool used by our team for time tracking, maintaining projects, and generating time and activity reports.
-   **Hubstaff** A workforce management platform that provides features for proof of work, time tracking, and payroll management.
-   **Microsoft Teams** A communication platform for team collaboration. Use it to stay in touch and discuss tasks, workflows, and issues in greater detail with your Pepperi team and PMs.
-   **outlook.office.com** A personal information manager web app that includes email, calendaring, contacts, and task management services.
-   **apidocs.pepperi.com** The Pepperi JS Client-Side API (Beta) enables integration with Native and Web Apps. The API runtime is available either from Rule-Engine-based User Defined Fields or Workflow’s Custom Web Forms.
-   **support.pepperi.com** A platform providing the basics of Pepperi configurations for troubleshooting and support.
-   **developer.pepperi.com** The Pepperi Developer Center offers API documentation, references, and resources needed to integrate applications with the Pepperi API.
-   **pepperi.talentlms.com** The educational Pepperi Training platform for learning and skill development.
-   **codesandbox.io** A testing environment for isolating untested code changes and conducting experiments outside the production environment.
